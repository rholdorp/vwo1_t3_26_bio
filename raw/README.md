# raw/

Hier komen de **foto's van de boekpagina's** die Stijn moet leren voor zijn proefwerk biologie (VWO 1, T3, week 26).

## Hoe toevoegen

1. Maak foto's van elke relevante pagina (recht boven, goed licht, zo scherp mogelijk).
2. Geef ze een logische naam, bijv:
   - `h05_p82_cellen.jpg`
   - `h05_p83_celorganellen.jpg`
   - `h06_p94_fotosynthese.jpg`
3. Zet ze in deze map.
4. Werk daarna `../data/content.json` bij met de begrippen, feiten, kruisverbanden en vragen die uit die pagina komen. Zie [`../data/SCHEMA.md`](../data/SCHEMA.md) voor het formaat en [`../tools/CONTENT_GUIDE.md`](../tools/CONTENT_GUIDE.md) voor de werkwijze.

> De foto's zelf worden **niet** door de webapp ingelezen (statische site, geen OCR in de browser). Ze dienen als bronmateriaal waar de leerstof uit overgenomen wordt naar `content.json`.
